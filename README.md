# Student Academic Progress Monitoring Dashboard

A Streamlit dashboard for student analytics.

Features:
- Excel upload
- Percentage calculation
- Current CGPA prediction
- Previous vs Current CGPA comparison
- Bright learner detection
- Slow learner detection
- Analytics charts
- Downloadable reports

Tech:
Python, Streamlit, Pandas, Matplotlib, OpenPyXL

Run:

pip install -r requirements.txt
streamlit run app.py
